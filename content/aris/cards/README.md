# /aris journey card art — the drop zone

Six cards, six images. Drop them here as `card-1` … `card-6` with any of
`.webp` / `.jpg` / `.jpeg` / `.png` (first of those found wins the slot)
and the page serves them at `/aris/cards/<n>`. No file yet = a built-in
laurel placeholder, never a broken image.

| # | Card |
|---|------|
| 1 | The noblest reader |
| 2 | The five nevers |
| 3 | The calling |
| 4 | Your key |
| 5 | What travels |
| 6 | The ledger |

3:2 landscape, ~1200×800 is plenty. They sit on both themes (Paper bone
and Candlelight dark) — self-contained backgrounds or transparency.
