A box set starts with the book you have open and grows one volume at a time. How you add the other books decides how much of each one arrives.

## Steps
1. Open the **Export** dialog and find the **Box Set — Combined EPUB** section. The book in the studio is always **Book One**; the set is built around it.
   say: Open Export and find the Box Set section. The book on your desk is always Book One, and the set is built around it.
   do: click "Export"; wait 1; show "Box Set — Combined EPUB"
2. Use **Add a Book…** to bring in the next volumes. A manuscript works — Word, PDF, EPUB, Markdown, plain text or RTF, or a zip of them — but a Beuk backup file (.beuk-backup.json, saved with **Export a backup**) brings the book whole: its own cover and every picture, not just its text. A locked Word file or PDF asks for its password.
   say: Add a Book brings in the next volumes. A manuscript works — Word, P D F, EPUB, Markdown, plain text or R T F — but a Beuk backup file brings the book whole: its own cover and every picture, not just its text.
   do: click "Add a Book…"; wait 1
3. Each book is listed under its own title, with its chapter and word counts, and any book can be removed again. Pictures from different books never mix, even when two books share the same art.
   say: Each book is listed under its own title, with its chapter and word counts, and any book can be removed again. Pictures from different books never mix, even when two books share the same art.
   do: show "Add a Book…"

## Takeaway
A manuscript carries a book's text; a backup file carries the book. For a set that should keep every cover and every picture, add backups.
