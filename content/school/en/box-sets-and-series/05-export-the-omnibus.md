The last step is the shortest: one button builds the whole set. The judgement is in what you pick before it, and what you do if the file comes out enormous.

## Steps
1. If the set is headed for a particular store, pick its platform preset — it applies to the combined package, the same as for a single book.
   say: If the set is headed for a particular store, pick its platform preset. It applies to the combined package, the same as for a single book.
   do: show "Box Set — Combined EPUB"
2. Choose **Build Box Set .epub**. Beuk assembles one volume in your browser: dividers, title pages, each book's sections in order, one table of contents.
   say: Then choose Build Box Set dot e-pub. Beuk assembles one volume: dividers, title pages, each book's sections in order, one table of contents.
   do: show "Build Box Set .epub"
3. Box sets add up — three image-rich novels can make a file some stores cap. If a store refuses on size, reduce image dimensions in the later volumes, or split the set into two.
   say: Box sets add up. Three image-rich novels can make a file some stores cap. If a store refuses on size, reduce the image dimensions in the later volumes, or split the set in two.
   do: show "Build Box Set .epub"

## Takeaway
One preset, one button, one volume. If the stores balk at the size, it is the pictures — shrink them in the later books, or make it two sets.
