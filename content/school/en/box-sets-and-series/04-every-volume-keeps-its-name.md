"tik-tok-of-oz-final-FINAL-2.docx" is not a title. In a box set, each volume's name comes from the book itself, so the dividers and the contents say what the author meant.

## Steps
1. A box-set volume's title is the book's own: a backup file's title, a Markdown file's frontmatter title, a Word file's document title. "Tik-Tok of Oz" stays "Tik-Tok of Oz", whatever the file was called.
   say: A volume's title is the book's own. A backup file's title, a Markdown file's front matter title, a Word file's document title. Tik-Tok of Oz stays Tik-Tok of Oz, whatever the file was called.
   do: show "Add a Book…"
2. The file name is used only when the file names no title — and then as written. If a volume shows up under its file name, the fix is in the source: give the manuscript its title, and add the book again.
   say: The file name is used only when the file names no title, and then as written. If a volume shows up under its file name, give the manuscript its title in the source file, and add the book again.
   do: show "Add a Book…"
3. The list under **Add a Book…** is the check: each volume under its own title, with its chapter and word counts. A book that imported with no chapters has the same cause as in Import — chapters are found by heading styles — and the same cure: fix the source and add it again.
   say: The list is the check: each volume under its own title, with its chapter and word counts. A book that arrives with no chapters has the same cause as in Import — chapters are found by heading styles — and the same cure.
   do: show "Box Set — Combined EPUB"

## Takeaway
Titles travel inside the books. Name the book in the book, and the box set's dividers and contents take care of themselves.
