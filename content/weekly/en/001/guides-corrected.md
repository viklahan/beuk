Two guides in the Help reading room had fallen behind the studio they describe.

The guide to store presets named six stores. The studio ships eleven. It also said the Apple Books and Kobo presets add accessibility metadata; in fact every Beuk package carries it, whichever preset is chosen.

The guide to print interiors named six trim sizes. There are twenty-four. It also said true PDF/X conversion would come in a later phase. It has already arrived: a signed-in writer's Store-ready? check converts the interior on Beuk's server and reads the result back.

## So it cannot happen quietly again

Both guides were rewritten from the studio's own lists of presets and trims, and a test now compares them. If the studio gains a store or a size and the guide does not, the test fails.

> A guide that is out of date is a small lie told patiently. We would rather a test fail.
