Export in Beuk offers eleven presets for the EPUB: Generic EPUB, Amazon KDP, Apple Books, Kobo, Nook, Draft2Digital, OverDrive, Smashwords, Tolino, Scribd and Google Play. Every one is built from the same manuscript. The difference is in the packaging.

## What actually changes

The KDP, Nook and Smashwords presets add a legacy guide, the cover, contents and start-of-text pointers that older reading devices navigate by. Apple Books adds the display-options file Apple Books actually reads. Draft2Digital carries both, because an aggregator feeds many stores at once.

Kobo, OverDrive, Tolino, Scribd and Google Play take the standard package as it stands, so their presets add nothing.

> Accessibility metadata is not a preset feature. Every Beuk package carries it, whichever store it is going to.

## Nothing invented

If a book has an ISBN, every preset uses it. If it doesn't, the book keeps its own identifier. Beuk never makes up an ASIN or a store number; the stores that assign their own do so when the file arrives.

The file name carries the preset, so a folder of exports never leaves you guessing which one goes where.
