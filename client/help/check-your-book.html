Check your book (the validator)

What you're doing: giving your export a once-over with the same scepticism a store's ingestion machine will use — before it ever leaves your desk.

Steps

  1. Open the Export dialog and pick the preset you'll actually ship.
  2. Choose Validate This Book.
  3. Read the results top-down: errors first, then warnings, then the passes. Every line is explained in plain language — what was checked, and if something failed, what to do about it.

What it checks

  • The mimetype entry is first in the package and stored uncompressed — the oldest EPUB rule there is.
  • container.xml points at a package file that is actually there.
  • Every XML and XHTML file is well-formed.
  • The manifest and the files agree both ways: nothing declared is missing, nothing present is undeclared, no duplicate identifiers.
  • The reading order (spine) resolves, end to end.
  • The navigation document carries its landmarks — contents, body matter, and cover when a cover ships — and the legacy NCX is present with targets that resolve.
  • Every internal link and anchor resolves, footnote back-links included.
  • Every image carries alt text.
  • Required metadata is present: title, author, identifier, language — and a declared cover is properly marked as the cover.

Warnings are advice, not failure

A missing cover, a missing description, or using the book's own identifier because there's no ISBN yet — the validator notes these as warnings, with the reason, and lets you ship anyway. Stores accept all three; the notes exist so the choices are yours, made knowingly.

What can go wrong — and one honest limit

The honest limit: this is structural validation. The full, official EPUBCheck suite runs on Beuk's servers in the SaaS phase — the validator will tell you so itself, in its own results panel. Beuk doesn't claim EPUBCheck's authority for a lighter set of checks.

It passed here but a store complained. Stores add rules of their own on top of the standard (cover pixel sizes, file-size caps). Copy the store's exact words into the error decoder.
